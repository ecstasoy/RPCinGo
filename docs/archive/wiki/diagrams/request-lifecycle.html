RPCinGo — Request Lifecycle

End-to-end journey of a single RPC call from client.Call() to response, with timing annotations.

Client Path

  • context + deadline propagation
  • interceptor chain (onion model)
  • connection pool acquire / release
  • binary encode to wire

Server Path

  • binary decode from wire
  • dispatcher via reflection
  • interceptor chain + handler execute
  • response encode back to wire

Wire Format

  • 20-byte fixed header always read first
  • RequestID enables concurrent multiplexing
  • codec: JSON (default) or Protobuf
  • compression: Gzip or Snappy optional
