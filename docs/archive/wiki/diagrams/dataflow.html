RPCinGo — Data Flow & Wire Format

From Go struct to bytes on the wire and back. Codec + compression + 20-byte binary header.

Wire Frame

  • Magic: 0xCAFE (2 bytes) — frame identifier
  • Version (1B) + MsgType req=1/resp=2 (1B)
  • CodecType (1B) + CompressType (1B)
  • RequestID: 8 bytes — enables multiplexing
  • BodyLen: 4 bytes — then read body

Codec

  • JSON: encoding/json, text-based, default
  • Protobuf: binary, schema-required, faster
  • Encode(interface{}) ([]byte, error)
  • Decode([]byte, interface{}) error

Compression

  • None (0): default, zero overhead
  • Gzip (1): best ratio, higher CPU cost
  • Snappy (2): fast compression, moderate ratio
  • Negotiated via CompressType header byte
