Swimlane sequence — from Client.Call() through interceptor chains, transport, to service dispatch and back

Interceptor Chains · onion model

  • • Client: tracing → retry → ratelimit → logging
  • • Server: recovery → logging → metrics → ratelimit → tracing
  • • Shared Chain builder — interceptor.NewChain
  • • First registered = outermost wrapper

Wire Protocol · 20B header + body

  • • Magic 2B · Version 1B · MsgType 1B
  • • Codec 1B · Compress 1B · Reserved 2B
  • • RequestID 8B · BodyLen 4B
  • • RequestID enables out-of-order multiplex

CircuitBreaker FSM · parallel chain

  • • Closed → Open: failure rate > threshold
  • • Open → HalfOpen: Timeout elapses
  • • HalfOpen → Closed: SuccessThreshold hits
  • • 10-bucket sliding window metrics

Discovery chain · etcd

  • • Registry.Register + lease KeepAlive
  • • Watcher pushes instance changes
  • • PoolManager maintains pool-per-address
  • • LoadBalancer.Pick selects instance

Codec chain · decorator

  • • CompressedCodec wraps base Codec
  • • Gzip / Snappy compression layers
  • • JSON / Protobuf base codecs
  • • Selection driven by header bytes

TCP concurrency gates

  • • Connection-count semaphore
  • • In-flight request semaphore
  • • Single persistent client connection
  • • Writes serialized via channel
